## 📌 Overview
This repository contains simple Bash scripts for:
- System information reporting
- Package checking
- Log file analysis

These scripts are lightweight, beginner-friendly, and useful for everyday Linux tasks.

---

## ⚙️ Scripts Included

### 1. System Report
Displays basic system information.

**Features:**
- Kernel version
- Current user
- System uptime
- Current date

---

### 2. Package Checker
Checks if a package (default: `git`) is installed.

**Features:**
- Verifies installation
- Displays version
- Provides a short description

---

### 3. Log Analyzer
Searches a log file for a keyword.

**Features:**
- Case-insensitive search
- Counts occurrences
- Default keyword: `error`
